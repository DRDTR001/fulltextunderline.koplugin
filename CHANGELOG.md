# Changelog

All notable changes to Full Text Underline are documented in this file.

## v1.0.0

Initial release.

### Added

- Solid line style
- Dashed line style
- Dotted line style
- Full-width underline mode
- Text-width underline mode
- Adjustable underline position
- Adjustable underline length
- Adjustable line thickness
- Optional heading underlines
- Per-book settings
- Plugin defaults for new books
- KOReader Reading Profile support
- Simplified Chinese interface
- English interface
