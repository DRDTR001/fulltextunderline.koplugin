# Full Text Underline v1.0.0

The first public release of Full Text Underline for KOReader.

## Highlights

- Draw solid, dashed, or dotted reading lines beneath visible text.
- Choose full-width lines or lines that follow each visual text line.
- Adjust line position, length, and thickness without changing book layout.
- Keep headings excluded by default or enable heading underlines.
- Save settings per book, define defaults for new books, and use KOReader Reading Profiles.
- Use the plugin in English or Simplified Chinese.

## Compatibility

- Recommended: KOReader v2025.xx or later
- Tested: KOReader v2026.07.1
- Platforms: Kindle, Kobo, and Android KOReader

Older 2024.x builds may not provide the required ReaderView APIs.

## Installation

1. Download `fulltextunderline-v1.0.0.zip` from the release assets.
2. Extract the archive.
3. Copy `fulltextunderline.koplugin` to `koreader/plugins/`.
4. Restart KOReader.

The plugin only draws into ReaderView. It does not modify EPUB files, reflow documents, or change pagination.
